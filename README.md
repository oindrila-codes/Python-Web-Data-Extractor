# Python Web Data Extractor

## Overview

A Python-based web scraping application developed using Requests and BeautifulSoup.

The program automatically visits multiple pages of an online bookstore, extracts book information, filters highly-rated books, and displays the results.

## Features

- Web scraping using Requests
- HTML parsing using BeautifulSoup
- Data extraction from multiple pages
- Filtering books based on ratings
- Console-based output

## Technologies Used

- Python
- Requests
- BeautifulSoup

## Project Workflow

1. Connect to website
2. Parse HTML content
3. Extract book information
4. Filter 4-star and 5-star books
5. Display results

## Output

The program prints the titles of highly-rated books collected from multiple pages.

## Learning Outcomes

- Web scraping fundamentals
- HTML parsing
- Data filtering
- Python automation
